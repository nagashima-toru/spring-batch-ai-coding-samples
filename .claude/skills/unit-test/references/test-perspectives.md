# 単体テスト観点表（境界値・異常系）

テストケース設計時にこの表と突き合わせ、対象に該当する観点の漏れがないか確認する。

## 1. 文字列項目

| 観点 | ケース例 |
|---|---|
| 必須 | null / 空文字 / 空白のみ |
| 桁数境界 | 最大桁ちょうど / 最大桁+1 |
| 文字種 | 許可外文字（記号・全角/半角の混在） |
| 前後空白 | トリム対象か仕様確認のうえ検証 |
| マルチバイト | 全角文字・サロゲートペア（絵文字）を含む値 |

## 2. 数値・金額項目

| 観点 | ケース例 |
|---|---|
| 境界値 | 0 / 最小値 / 最大値 / ±1 |
| 符号 | 負数（許可/拒否の仕様どおりか） |
| 形式 | 数字以外 / 先頭ゼロ / 小数（整数のみの項目に対して） |
| 丸め | 端数処理の方向（切捨て/四捨五入）と桁 |

## 3. 日付項目

| 観点 | ケース例 |
|---|---|
| 形式 | 不正フォーマット / 存在しない日付（2/30） |
| 境界 | 月末・年末年始・うるう年（2/29） |
| 範囲 | 過去日・未来日の許容範囲 |

## 4. 変換・計算ロジック

| 観点 | ケース例 |
|---|---|
| 代表値 | 正常系の代表的な入力→期待出力 |
| ゼロ件・空 | 空コレクション / null 要素 |
| コード変換 | 未定義コード（デフォルト or エラーの仕様どおりか） |
| 集計 | 1件のみ / 同一キー複数件 / 合計が桁あふれしない上限付近 |

## 5. 例外・エラー処理

| 観点 | ケース例 |
|---|---|
| 例外の型 | 業務エラー → BusinessException（Skip 対象）になっているか |
| 例外の型 | 環境エラー → SystemException（即失敗）になっているか |
| メッセージ | 原因特定に足る情報（項目名・値・キー）を含むか |
| フィルタ | Processor が null を返すケース（Skip とフィルタの区別） |

## 6. Tasklet

| 観点 | ケース例 |
|---|---|
| 正常 | RepeatStatus.FINISHED を返す |
| 前提NG | 対象なし・ファイルなし等での例外送出 |
| 依存の呼び出し | モックの呼出回数・引数の検証（副作用の確認） |

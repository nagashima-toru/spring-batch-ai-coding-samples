# T-03 README に ライセンス・コントリビュート・注意事項 の節を追記する

## 目的
公開後に README を読んだ第三者が、ライセンス条件・Issue と PR の受け付け方針・雛形としての注意点（無保証・例示値）を README だけで分かるようにする。

## 入力
- `README.md`（現状。末尾が「## CD（デプロイ）の前提設定」）
- `LICENSE`（T-02 で追加済み）
- `docs/aws-setup.md`（AWS アカウント ID `123456789012` 等の例示値を含む）
- 計画票 `vault/plans/P-20261012-make-repo-public.md` の「人への質問」1〜3

## 成果物
- `README.md`（1ファイル。既存の節は変えず、末尾に3節を追記する）

## 受け入れ基準
- README に3つの節がこの順で末尾に追加されている。確認：`grep -nE '^## ' README.md | tail -3` の出力の3行の見出しが上から `## ライセンス`・`## コントリビュート`・`## 注意事項`
- ライセンス節が LICENSE へのリンクと著作権者の表記を持つ。確認：`grep -cE '^\[Apache License 2\.0\]\(LICENSE\) の下で公開しています。Copyright 2026 Toru Nagashima$' README.md` の出力が `1`
- リンク先の LICENSE が存在する。確認：`git ls-files --others --cached --exclude-standard -- LICENSE` の出力が `LICENSE`
- コントリビュート節が Issue 先行の PR 方針を書いている。確認：`grep -cF 'Pull Request は事前に Issue で相談したうえで受け付けます' README.md` の出力が `1`
- 注意事項節が AWS の値が例示値であることを書いている。確認：`` grep -cE '^- `docs/aws-setup\.md` の AWS アカウント ID（`123456789012`）・ARN は例示値です' README.md `` の出力が `1`
- README のバッククォート内のパスがすべて存在する。確認：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`

## 決定済み
- 追記は README の末尾（現在の最終節「## CD（デプロイ）の前提設定」の後）に、`## ライセンス`・`## コントリビュート`・`## 注意事項` の順で行う。既存の節・文言は変えない
- `## ライセンス` の本文は次の1行をそのまま書く：`[Apache License 2.0](LICENSE) の下で公開しています。Copyright 2026 Toru Nagashima`（ライセンス種別・著作権者は計画票の人への質問1・2の案。人が別案を回答した場合は承認前にこの票が書き換えられる）
- `## コントリビュート` には次の3点を書く。文言「Pull Request は事前に Issue で相談したうえで受け付けます」をそのまま含める
  - 不具合報告・質問は Issue で受け付ける
  - Pull Request は事前に Issue で相談したうえで受け付けます
  - 対応や回答は保証しない（個人で保守している雛形のため）
- `## 注意事項` は箇条書きで、次の行を含める
  - `` - `docs/aws-setup.md` の AWS アカウント ID（`123456789012`）・ARN は例示値です。実際の値に置き換えて使ってください `` の文（行頭から「は例示値です」までをこのとおりに書く）
  - 本リポジトリは学習・雛形用のサンプルで、無保証（LICENSE のとおり）であること
  - ローカル用の DB パスワード（`docker/compose.yaml`・`application-local.yml`）はローカル専用の固定値で、本番系は Secrets Manager / SSM から環境変数で注入すること
  - `vault/` は AI 協働ハーネスの作業領域（計画票・タスク票など）で、雛形の利用には不要であること
- README には、この計画で新しく作る docs（棚卸しレポート・公開手順チェックリスト）のパスを書かない（公開手順はリポジトリ所有者向けの作業で、利用者向けの README の範囲外のため。あわせて `(ref-1)` の順序の制約を避ける）
- バッククォートで書くパスは、既に存在する `docs/aws-setup.md`・`docker/compose.yaml` などに限る（`(ref-1)` は `vault/`・`scripts/`・`docs/`・`.claude/` で始まるパスの存在を見る）
- `CLAUDE.md`・`docs/` 配下は変えない

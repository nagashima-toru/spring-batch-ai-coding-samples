# T-02 LICENSE（Apache License 2.0 の原文）を追加する

## 目的
公開後に第三者がこの雛形を利用・改変・再配布できる条件を明示するため、リポジトリのルートにライセンスの原文を置く（GitHub がライセンスを自動判別できる形にする）。

## 入力
- Apache License 2.0 の原文：https://www.apache.org/licenses/LICENSE-2.0.txt
- 計画票 `vault/plans/P-20261012-make-repo-public.md` の「人への質問」1・2

## 成果物
- `LICENSE`（1ファイル。リポジトリのルート）

## 受け入れ基準
- `LICENSE` が Apache License 2.0 の原文（https://www.apache.org/licenses/LICENSE-2.0.txt）とバイト単位で一致する。確認：`sha256sum LICENSE` の出力の先頭が `cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`
- `LICENSE` が 202 行である。確認：`wc -l LICENSE` の出力が `202 LICENSE`
- 本文の見出しが Apache License 2.0 のものである。確認：`grep -cE '^ +(Apache License|Version 2\.0, January 2004)$' LICENSE` の出力が `2`
- リポジトリのルートにほかのライセンスファイルが無い。確認：`git ls-files --others --cached --exclude-standard -- 'LICENSE*' 'COPYING*' 'LICENCE*'` の出力が `LICENSE` の1行だけ

## 決定済み
- ライセンス種別は Apache License 2.0（計画票の人への質問1の案。人が MIT と回答した場合は、承認前にこの票の成果物・受け入れ基準が書き換えられる）
- 原文は `curl -sS -o LICENSE https://www.apache.org/licenses/LICENSE-2.0.txt` で取得し、一切編集しない（改行・空白・末尾の付録「APPENDIX: How to apply the Apache License to your work.」の雛形 `[yyyy] [name of copyright owner]` もそのまま残す）。取得できない時は手で書き起こさず `blocked` にする
- 著作権者の表記（`Copyright 2026 Toru Nagashima`）は LICENSE には書かない。README のライセンス節に書く（T-03 の担当）
- `NOTICE` ファイルは作らない（Apache-2.0 では任意で、同梱すべき第三者の NOTICE も無いため）
- `pom.xml` の `<licenses>` 要素は変えない（次フェーズの候補）

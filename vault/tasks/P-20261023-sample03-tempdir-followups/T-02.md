## 決定済み
- `Sample03JobConfigTest` にテストメソッドをちょうど1つ足す。名前は `outputFileにNUL文字を含む場合＿InvalidJobParametersExceptionで起動を拒否する`。既存の9件（T-01 の後）は変えず、ほかのテストは足さない（受け入れ基準が件数 `10` を見るため）
- テストの中身：`@TempDir Path dir` を受け取り、`outputFile` に `dir.toString() + "/sales\u0000.csv"`（Java のソース上は `\u0000` のエスケープで書く）を入れ、`tempDir` は入れない `JobParameters`（`JobParametersBuilder` の `addString`）で `Sample03JobConfig.validateParameters` を呼ぶ。`assertThatThrownBy` で `InvalidJobParametersException` が出て、メッセージに `パスとして解釈できません` を含み、NUL 文字（`"\u0000"`）を含まない（`doesNotContain`）ことを確かめる
- `tempDir` を入れないのは、`outputFile` 側の `Path.of` で拒否されることを示すため（`tempOutputOf` は `tempDir` が無い時も `Path.of(outputFile)` を呼ぶ）
- `Sample03JobConfig.java` は変えない（`validateTempOutput` は `outputFile` の `InvalidPathException` もすでに変換している。PR #109）。もしテストが通らず本体の変更が要ると分かったら、本体を変えずに blocked にして理由を question に書く
- 結合テスト（`Sample03FileExportJobIT.java`）と `batch-sample/docs/sample03-file-export.md` は変えない。受け入れ基準に `./mvnw clean verify`（結合テスト込み）は入れず、計画単位のレビュータスク T-04 で実行する
- ビルドのコマンドはシェルの `JAVA_HOME` が JDK 21 を指すため、受け入れ基準のとおり `JAVA_HOME=/usr/lib/jvm/java-25-openjdk-amd64` を前に付けて実行する

# T-02 CLAUDE.md の Skills の節から development-guide.md §2.4 へリンクする

## 目的
`CLAUDE.md` の「Skills（開発工程）」の節から、T-01 で足した `docs/development-guide.md` §2.4（ハーネスで実装以降を進める場合）へ辿れるようにする。

## 入力
- `CLAUDE.md`（「## Skills（開発工程）」の節と、末尾のハーネスのマーカーブロック）
- `docs/development-guide.md` §2.4（T-01 の成果物。見出し `### 2.4 ハーネスで実装以降を進める場合`）
- `vault/designs/D-20261011-spring-batch-adapt.md`（フェーズ2節。マーカーブロックを変えない理由）

## 成果物
- `CLAUDE.md`（1ファイル。「## Skills（開発工程）」の節への追記だけ）

## 受け入れ基準
- `CLAUDE.md` に決定済みのリンクがちょうど1つある（`grep -c -F '](docs/development-guide.md#24-ハーネスで実装以降を進める場合)' CLAUDE.md` が `1`）
- そのリンクの行が「## Skills（開発工程）」の見出しより後、「## 禁止事項」の見出しより前にある（`grep -n -e '^## ' -e 'docs/development-guide.md#24-' CLAUDE.md` の出力の並びで確かめる）
- リンク先の見出しが実在する（`grep -c -x -F '### 2.4 ハーネスで実装以降を進める場合' docs/development-guide.md` が `1`）
- ハーネスのマーカーブロックが元の4行のまま連続している（`grep -A3 -F '<!-- ai-harness:begin v1 -->' CLAUDE.md` の出力が `<!-- ai-harness:begin v1 -->`・`# AI協働ハーネス 共通ルール`・`@.claude/ai-harness.md`・`<!-- ai-harness:end -->` の4行）
- マーカーブロックの行に差分が無い（`git diff main -- CLAUDE.md | grep -cE '^[+-](<!-- ai-harness|# AI協働ハーネス|@\.claude/ai-harness\.md)'` が `0`）

## 決定済み
- 追記の場所は「## Skills（開発工程）」の節の末尾（`/sdd-pipeline` を説明する段落の直後、「## 禁止事項」の直前）
- 追記する文は、詳細設計がレビュー済みのジョブの implementation〜system-test は、`/sdd-pipeline` の代わりにハーネス（`/plan`・`/run`）でも進められること、使い分けはリンク先にあることを1〜2行で書き、リンクは `[docs/development-guide.md §2.4](docs/development-guide.md#24-ハーネスで実装以降を進める場合)` をそのまま使う（アンカーは GitHub の見出しアンカー規則で `2.4` が `24` になったもの）
- Skills の表（`/requirements`〜`/system-test` の行）と既存の段落は変えない。`/plan`・`/run` の行を表に足さない（ハーネスのスキルはマーカーブロックが読み込む `.claude/ai-harness.md` で案内済みのため）
- ハーネスのマーカーブロック（`<!-- ai-harness:begin v1 -->`〜`<!-- ai-harness:end -->`）は `install.sh --update` が書き換えるので、手で編集しない
- 確認コマンドの `git diff main` は、このファイルを変えるのがこの計画で T-02 だけなので誤検知しない
- 文章は日本語で書く

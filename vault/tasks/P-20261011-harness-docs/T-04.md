# T-04 設計文書 D-20261011-spring-batch-adapt を削除する

## 目的
全フェーズの計画を作り終え、決定事項を docs（T-01・T-02）と `docs/decisions.md`（T-03）に移したので、設計文書 `vault/designs/D-20261011-spring-batch-adapt.md` を削除する（`docs/vault-spec.md` 13節「最終フェーズでの削除」）。

## 入力
- `vault/designs/D-20261011-spring-batch-adapt.md`（削除対象）
- `docs/vault-spec.md` 13節「最終フェーズでの削除」
- `docs/decisions.md`（T-03 の成果物）、`docs/development-guide.md` §2.4（T-01 の成果物）

## 成果物
- `vault/designs/D-20261011-spring-batch-adapt.md` の削除（1ファイル）

## 受け入れ基準
- 設計文書が無い（`test ! -e vault/designs/D-20261011-spring-batch-adapt.md` の終了コードが `0`）
- 削除した設計文書のパスへの参照が、docs・CLAUDE.md・README・`.claude/`・`scripts/` に残っていない（`grep -rn --exclude-dir=worktrees 'vault/designs/D-20261011-spring-batch-adapt' docs CLAUDE.md README.md .claude scripts` の出力が空）
- 決定事項の移し先が残っている（`grep -c '| D-20261011-spring-batch-adapt |$' docs/decisions.md` が `4`、`grep -c -x -F '### 2.4 ハーネスで実装以降を進める場合' docs/development-guide.md` が `1`）

- smoke 全体が通る（`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる）

## 決定済み
- 削除は creator がこのタスクの成果物として行う（`vault/designs/` は差分ゲートの禁止対象ではない）。`git rm` でも通常の削除でもよい。ディレクトリ `vault/designs/` が空になっても、ディレクトリ自体の扱い（`.gitkeep` の追加など）はしない
- 参照の残りを検査する範囲から `vault/` を除く。この計画の計画票・タスク票・log・verdict が設計文書のパスを書いており、これらは run が書く状態ファイルで、run が PR を作る直前に `scripts/purge_plan.sh` で除去する対象のため
- `docs/decisions.md` の出典は ID（`D-20261011-spring-batch-adapt`）で、パスではないので参照の残りに当たらない
- 参照の残りの検査では `.claude/worktrees/`（run が作る creator の worktree。各 worktree に計画票・タスク票の写しがある）を `--exclude-dir=worktrees` で除く
- 他のファイルは変えない。参照の残りが見つかった時は自分で直さず、`blocked: <見つかったファイルと行>` で返す
- smoke の実行には1分ほどかかる

# T-01 一時出力→配置の一時ファイルのパスを決める TempOutputFile を batch-core に足す（#72）

## 決定済み
- 方式は Issue #72 の (B)（一時ファイルのパスを決めてディレクトリを作るヘルパー）。`FileMoveTasklet` は変えない（理由は計画票の「分割方針」。一時ファイルは別のディレクトリに同名で置くので別名への移動は要らない）
- クラスは `com.example.batch.core.tasklet.TempOutputFile`。`public final class` にし、コンストラクタは private、生成は次の2つの static メソッドだけにする（record にしない。正準コンストラクタが公開されて検査を通らない生成ができるため）
  - `public static TempOutputFile inSubdirectory(Path outputFile, String dirName)`：一時ディレクトリを「配置先の親ディレクトリ配下の `dirName`」にする
  - `public static TempOutputFile inDirectory(Path outputFile, Path tempDir)`：一時ディレクトリを `tempDir` にする（配置先の外にも置ける）
- 生成時の値：`outputFile` は `toAbsolutePath().normalize()` したものを持つ。`outputDir` はその親、`tempDir` は `inSubdirectory` なら `outputDir.resolve(dirName)`、`inDirectory` なら `tempDir.toAbsolutePath().normalize()`、`tempFile` は `tempDir.resolve(outputFile のファイル名)`
- 公開するメソッド：`public Path outputFile()`・`public Path outputDir()`・`public Path tempDir()`・`public Path tempFile()`（いずれも生成時に決めた値を返すだけ）と、`public Path prepare()`（`Files.createDirectories(tempDir)` を呼んで `tempFile` を返す）
- 生成時の検査（どれも `com.example.batch.core.exception.SystemException` を送出する。設定・パラメータの不備で、環境を直さないと解消しないため。`RuntimeException` を直接送出しない）
  - `outputFile` のファイル名か親ディレクトリが無い（ルートパスなど）：メッセージは `配置先にファイル名がありません: ` に続けて `outputFile`
  - `tempDir` が `outputFile` と同じ、または `outputDir` と同じ（一時ファイルが配置先そのものになり移動できない）：メッセージは `一時ディレクトリが配置先と重なります: tempDir=` に続けて `tempDir`、` outputFile=` に続けて `outputFile`
- `prepare()` で `IOException` が起きたら、`new SystemException("一時ディレクトリを作成できません: " + tempDir, e)` で cause を付けて送出する
- 入力の null の検査は足さない（既存の部品と同じく呼び出し側の責務）
- クラスの Javadoc には docs/coding-standards.md §2 の「用途・使い方・拡張ポイント」の3点を書く
  - 用途：一時出力→配置で、一時ファイルのパスを決めて一時ディレクトリを作る。途中で失敗しても配置先に不完全なファイルを出さないため
  - 使い方：Writer の Bean で `prepare()` の戻り値を出力先にし、`new FileMoveTasklet(temp.tempFile(), temp.outputDir(), true)` で配置先へ移す例を `{@code ...}` の `pre` で示す
  - 「一時ディレクトリは配置先と同じファイルシステムに置く（別のファイルシステムだと移動がコピーになり、配置先に書きかけのファイルが見える）。」の文を1回だけ書く（受け入れ基準がこの語を探す。メソッドの Javadoc には同じ語を書かない）
  - 配置先のディレクトリを再帰的に監視する仕組みがある時は、`inDirectory` で一時ディレクトリを配置先の外に置くことを1文で書く
  - 拡張ポイント：final で継承しない。一時ディレクトリの場所は `inDirectory` で選ぶ
- 単体テスト `TempOutputFileTest` は JUnit 5 ＋ AssertJ、`@TempDir` を使い、Spring コンテキストを起動しない。メソッド名は次の7つにする（受け入れ基準が surefire のレポートで3つを探す）
  - `配下のディレクトリ名を指定した場合＿配置先の親ディレクトリ配下に同名の一時ファイルパスを返す`：`inSubdirectory(dir.resolve("sales.csv"), "tmp")` の `tempFile()` が `dir.toAbsolutePath().resolve("tmp").resolve("sales.csv")`、`outputDir()` が `dir.toAbsolutePath()`
  - `一時ディレクトリを指定した場合＿そのディレクトリ配下に同名の一時ファイルパスを返す`：`inDirectory(dir.resolve("out").resolve("sales.csv"), dir.resolve("work"))` の `tempFile()` が `dir.toAbsolutePath().resolve("work").resolve("sales.csv")`
  - `一時ディレクトリが配置先と同じパスの場合＿SystemExceptionを送出する`：`inSubdirectory(dir.resolve("tmp"), "tmp")`
  - `一時ディレクトリが配置先の親ディレクトリと同じ場合＿SystemExceptionを送出する`：`inDirectory(dir.resolve("sales.csv"), dir)`
  - `ファイル名の無いパスの場合＿SystemExceptionを送出する`：`inSubdirectory(Path.of("/"), "tmp")`
  - `prepareを呼んだ場合＿一時ディレクトリを作成し一時ファイルのパスを返す`：戻り値が `tempFile()` と等しく、`tempDir()` がディレクトリとして存在する
  - `一時ディレクトリを作成できない場合＿SystemExceptionを送出する`：`tempDir` の位置に通常のファイルを置いてから `prepare()` を呼ぶ
- テストメソッド名の区切りは全角の `＿`（既存のテストと同じ）
- このタスクでは sample03・`batch-sample/docs/`・`.claude/skills/` を変えない（T-02 で行う）

# T-01 development-guide §1.3 のサンプル01実行例を inputFile/errorFile に直す

## 目的
`docs/development-guide.md` §1.3 のサンプルジョブ実行例を、sample01 の必須パラメータ `inputFile` / `errorFile` を渡す形に直し、Issue #59 を解消する。

## 入力
- `docs/development-guide.md` §1.3「よく使うコマンド」（現在43行目の `-Dspring-boot.run.arguments=...importDate=2026-07-14,java.time.LocalDate"`）
- `batch-sample/docs/sample01-csv-import.md` の「実行方法」（正しいパラメータの出典）
- `batch-sample/src/main/java/com/example/batch/sample/job01_csv_import/Sample01JobConfig.java`（`JobParametersValidators.required("inputFile", "errorFile")`）

## 決定済み
- 変えるのは `docs/development-guide.md` §1.3 のコードブロック内、`./mvnw spring-boot:run -pl batch-sample \` に続く `-Dspring-boot.run.arguments="..."` の行だけ。`./mvnw spring-boot:run -pl batch-sample \` の行と、その上のコメント `# サンプルジョブのローカル実行（プロファイル local）` は変えない
- 置き換え後の行は次の1行にする（行頭の2スペースのインデントを保つ。行の継続 `\` で複数行に割らない）：
  `  -Dspring-boot.run.arguments="--spring.batch.job.name=sample01CsvImportJob inputFile=batch-sample/data/in/customers.csv errorFile=batch-sample/data/error/customers_error.txt"`
- パラメータ値は `batch-sample/docs/sample01-csv-import.md` の実行方法と同じにする（`inputFile=batch-sample/data/in/customers.csv`・`errorFile=batch-sample/data/error/customers_error.txt`）。`batch-sample/data/error/` ディレクトリが現時点で存在しないことは気にしない（出典の文書と揃えることを優先し、ディレクトリやファイルは作らない）
- `importDate` は development-guide.md から完全に無くす。代わりの日付パラメータは足さない（sample01 は日付パラメータを使わない）
- `importDate` が残っていないことの確認範囲は `docs/development-guide.md` のみとする。`docs/architecture.md` §1.2 の同じ誤った例は T-02 で扱うので、このタスクでは変えない（§11 命名規約表の `importDate` は命名例で誤りではなく、T-02 でも変えない）
- `docs/architecture.md`・README.md・CLAUDE.md・`batch-sample/docs/` 配下・コードは変えない
- `docs/development-guide.md` は smoke の `(ref-1)` の検査対象外なので、smoke の実行は不要
- ビルド（`./mvnw`）は文書のみの変更なので受け入れ基準に含めない

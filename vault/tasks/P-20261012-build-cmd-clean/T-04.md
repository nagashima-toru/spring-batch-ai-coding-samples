# T-04 sdd-pipeline Skill のビルドコマンドを clean 付きにそろえる

## 目的
sdd-pipeline Skill の手順7（コードレビュー）・手順9（最終検証）・読み替え表のビルドコマンドを `./mvnw clean verify` にそろえる（Issue #45）。

## 入力
- `.claude/skills/sdd-pipeline/SKILL.md`（86行目付近の手順7、90行目付近の手順9、123行目付近の読み替え表）
- `vault/rules/verifier/build-verification.md`（3コマンドの使い分けの正本）

## 成果物
- `.claude/skills/sdd-pipeline/SKILL.md`（1ファイル）

## 受け入れ基準
- `grep -n 'mvnw verify' .claude/skills/sdd-pipeline/SKILL.md` の出力が空（clean の無い `./mvnw verify` が残っていない）
- `grep -c 'mvnw clean verify' .claude/skills/sdd-pipeline/SKILL.md` が `3`（手順7・手順9・読み替え表）
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`

## 決定済み
- 3か所とも `./mvnw verify` を `./mvnw clean verify` に置き換える。手順7・9は結合テストを含む全体の確認なので `-DskipITs` は付けない
- 手順9の「最終検証」に、`clean` を付ける理由（`target/` に残った JaCoCo の実行データで結果が変わらないようにするため）を1文で足してよい（必須ではない）。足す場合も `./mvnw clean verify` の文字列は手順9の中で1行にだけ書く（`grep -c` の期待値 `3` を保つ）
- 手順9が参照する `development-guide.md` §3 手順3 は T-06 で直すので、このタスクでは参照の文言を変えない
- 置き換え以外の手順・表の構成は変えない

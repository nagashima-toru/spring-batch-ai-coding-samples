# T-05 PR テンプレート（既定・実装 PR 用）のビルドコマンドを clean 付きにそろえる

## 目的
既定の PR テンプレートと実装 PR 用テンプレートのセルフチェックにある `./mvnw verify` を `./mvnw clean verify` にそろえる（Issue #45）。

## 入力
- `.github/pull_request_template.md`（15行目付近の「確認したこと」）
- `.github/PULL_REQUEST_TEMPLATE/implementation.md`（23行目付近の「セルフチェック」）

## 成果物
- `.github/PULL_REQUEST_TEMPLATE/implementation.md`（主な成果物）
- `.github/pull_request_template.md`（付随して変える）

## 受け入れ基準
- `grep -rn 'mvnw verify' .github/pull_request_template.md .github/PULL_REQUEST_TEMPLATE` の出力が空（clean の無い `./mvnw verify` が残っていない）
- `grep -c 'mvnw clean verify' .github/PULL_REQUEST_TEMPLATE/implementation.md` が `1`
- `grep -c 'mvnw clean verify' .github/pull_request_template.md` が `1`

## 決定済み
- 2か所とも `./mvnw verify` を `./mvnw clean verify` に置き換える。`-DskipITs` は付けない（実装 PR は結合テストを含む最終状態で確かめるため）
- 置き換え以外のチェック項目・括弧内の補足は変えない
- `.github/PULL_REQUEST_TEMPLATE/design.md` にはビルドコマンドが無いので変えない
- `.github/workflows/ci.yml` は変えない（CI は毎回クリーンなチェックアウトで `target/` が無く、結合テストを含む `verify` なので判定がぶれない）

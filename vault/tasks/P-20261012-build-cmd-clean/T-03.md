# T-03 review-code Skill とチェックリストのビルドコマンドを clean 付きにそろえる

## 目的
review-code Skill の手順3・パイプライン実行時の例外条項と、コードレビューチェックリストのビルドコマンドを `./mvnw clean verify` にそろえる（Issue #45）。

## 入力
- `.claude/skills/review-code/SKILL.md`（23行目付近の手順3、34行目付近の例外条項）
- `.claude/skills/review-code/references/code-review-checklist.md`（57行目付近の「G. テスト」）
- `vault/rules/verifier/build-verification.md`（3コマンドの使い分けの正本）

## 成果物
- `.claude/skills/review-code/SKILL.md`（主な成果物）
- `.claude/skills/review-code/references/code-review-checklist.md`（付随して変える）

## 受け入れ基準
- `grep -rn 'mvnw verify' .claude/skills/review-code` の出力が空（clean の無い `./mvnw verify` が残っていない）
- `grep -c 'mvnw clean verify' .claude/skills/review-code/SKILL.md` が `2`（手順3と例外条項）
- `grep -c 'mvnw clean verify' .claude/skills/review-code/references/code-review-checklist.md` が `1`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`

## 決定済み
- 3か所とも `./mvnw verify` を `./mvnw clean verify` に置き換える。レビューは結合テストを含む全体の結果（batch-sample のカバレッジ80%を含む）を見るので `-DskipITs` は付けない
- 置き換え以外の文言（確認する項目の列挙・括弧内の補足）は変えない。`clean` の理由を足す場合は1文までにする（必須ではない）
- `./mvnw clean verify` を書く行はそれぞれ1行に収め、同じ行にもう1回書かない（`grep -c` は行数を数えるため、基準の期待値 `2`・`1` がずれないようにする）
- `vault/rules/verifier/build-verification.md` は変更しない

## 進捗
- 読んだルール: vault/rules/common/project-docs.md, vault/rules/creator/skill-workflow.md
- SKILL.md（手順3・例外条項）とcode-review-checklist.md（G. テスト）の `./mvnw verify` を `./mvnw clean verify` に置換
- 確認: grep -rn mvnw verify は空 / SKILL.md の clean verify は2 / checklist は1 / smoke の ref-1 ok は1。全基準OK

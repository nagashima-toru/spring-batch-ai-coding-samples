# T-02 TempOutputFile.prepare が残った一時ファイルを消さず Writer の上書きに任せる方針を Javadoc と単体テストで示す（#106）

## 目的
前回の失敗で残った同名の一時ファイルを `prepare` が消さないことを方針として明文化し、batch-core の Writer（`shouldDeleteIfExists(true)`）が上書きして前回の中身が残らないことを単体テストで確かめる。

## 決定済み
- 方針は「上書きに任せる」。`prepare` は一時ディレクトリを作って一時ファイルのパスを返すだけで、残った一時ファイルを消さない・失敗させない（コードの動作は変えない）。理由：
  - batch-core の `CsvItemWriterFactory`・`FixedLengthItemWriterFactory` は `shouldDeleteIfExists(true)` で、リスタートでない実行では Writer が開く時に既存の一時ファイルを消して書き直す
  - Writer が `saveState=true` でリスタートする時は、Spring Batch が保存した位置から一時ファイルに書き継ぐので、`prepare` で消すとリスタートを壊す
  - 残っていれば失敗させると、失敗後の再実行（一時ファイルが残るのが通常）が止まる
- `prepare` の Javadoc に、文言「前回の失敗で残った同名の一時ファイルは消さない（Writer の上書きに任せる）」をそのまま含めて書く。続けて、`shouldDeleteIfExists(true)` の Writer（batch-core の Writer の生成部品の既定）ならリスタートでない実行で上書きされること、`saveState=true` のリスタートでは保存した位置から書き継ぐこと、追記する Writer（`shouldDeleteIfExists(false)` や `append(true)`）と組み合わせないことを書く
- 追加する単体テスト（`@Test` の通常のメソッド。名前はこのとおりにする）：
  - `前回の一時ファイルが残っている場合＿prepareは消さずに一時ファイルのパスを返す`：一時ディレクトリと一時ファイル（中身 "old"）を先に作り、`prepare` の後も一時ファイルの中身が "old" のままであることを確かめる
  - `前回の一時ファイルが残っている場合＿CsvItemWriterFactoryのWriterが上書きする`：一時ファイル（中身に前回の行）を先に作り、`CsvItemWriterFactory.create` で `prepare` の戻り値を出力先にした Writer を作って、新しい `ExecutionContext` で `open`・`write`・`close` し、ファイルに前回の行が残らず今回の行だけがあることを確かめる。レコード型はテスト内の record でよい
  - 「前回の一時ファイルが残っている場合」で始まるテストメソッドはこの2件だけにする
- T-01 で足したテストと既存テストは変えない
- `batch-sample` 配下と `batch-sample/docs/sample03-file-export.md` は変えない（sample03 の文書への方針の記載は T-03 で行う）

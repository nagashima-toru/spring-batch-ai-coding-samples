## 決定済み
- 人の回答：smoke の `(install-gi) 03` は B（`.gitignore` に `.claude/worktrees/` を手で先に追記してから `install.sh --update`）で確定
- このタスクは、フック（`.claude/hooks/stop_gate.py`）・エージェント定義（`.claude/agents/`）・スキル（`.claude/skills/`）を更新すること自体が目的。「基準を満たすためにフック・設定を触った」には当たらないので、blocked にせず進めてよい。書き換えは Edit/Write ツールではなく `install.sh --update` に任せる（ファイルを手で編集しない。例外は `.gitignore` の1行の追記だけ）
- 手順は次の順で、1回の Bash に1コマンドずつ実行する（`&&`・`;`・`cd` を使わない）
  1. `mkdir -p /tmp/claude/P-20261012-harness-update-T-01`
  2. `/tmp/claude/P-20261012-harness-update-T-01/ai-harness` が無ければ `git clone https://github.com/nagashima-toru/ai-harness.git /tmp/claude/P-20261012-harness-update-T-01/ai-harness`。既にあれば（再開時）`git -C /tmp/claude/P-20261012-harness-update-T-01/ai-harness fetch origin` を実行する。既存の clone が壊れていて使えない時は、削除せず `/tmp/claude/P-20261012-harness-update-T-01/ai-harness-2` に clone し直す
  3. `git -C <clone> checkout --detach 6c1063a2c1a38a838ade55ebc500e2c5a6dffa5d` を実行し、`git -C <clone> rev-parse HEAD` が `6c1063a2c1a38a838ade55ebc500e2c5a6dffa5d`、`git -C <clone> status --porcelain` が空であることを確かめる
  4. worktree の `.gitignore` の末尾（`*.bak-*` の行の次）に `.claude/worktrees/` の1行を追記する（既にあれば足さない）。install より先に行う
  5. worktree のルートで `bash <clone>/scripts/install.sh --update .` を実行する（導入先は creator の worktree のルート。メインのリポジトリのパスを渡さない）。`--no-claude-md` は付けない（事前の試行で CLAUDE.md は skip になり変わらない）
  6. 受け入れ基準のコマンドを実行する
- clone はリポジトリの外（上記の `/tmp/claude/` の固定パス）に置く。worktree の中に置かない（`transition.py` の収集コミットが `git add -A` で取り込むため）。clone の削除はしない（人にも頼まない）
- `.gitignore` を先に追記する理由：そのまま install すると manifest に `"gitignore": "appended"` が残り、smoke が導入元としてこのリポジトリを使う時にそのキーが一時導入先に引き継がれて `(install-gi) 03` が NG になる。先に追記すると install は `.gitignore` を変えず、manifest に `gitignore` キーを書かない。追記の結果の `.gitignore` は install が追記した場合と同じ内容になる
- 事前の試行（このリポジトリの clone に同じ手順を実行）での結果：変更されるのは「成果物」に挙げた15パス（`.gitignore` を含む）だけ。`.claude/settings.json` と `CLAUDE.md` は skip、利用者が編集済みでスキップされたものは無し。install の出力に `skip (edited)` が出た時や、`git status --porcelain` に成果物以外のパスが出た時は、手で直さず `blocked:` でそのパスと install の出力を返す
- `install.sh` が出力の最後に案内する `next:`（`cd ... && bash scripts/smoke.sh && claude`）は実行しない。smoke は受け入れ基準のコマンドで実行する
- manifest の `version` は install の実行時刻になる（値は基準にしない）
- ai-harness 側にだけある `vault/rules/planner/ai-harness-lessons.md` などの利用者資産（install が配らないもの）・ai-harness の `README.md`・`docs/guide.md` 等は取り込まない（install の配布対象外で、このリポジトリの資産ではないため）。このリポジトリの `docs/development-guide.md` も変えない
- コミットはしない（受け入れ基準にコミットは無い。収集は transition.py が行う）

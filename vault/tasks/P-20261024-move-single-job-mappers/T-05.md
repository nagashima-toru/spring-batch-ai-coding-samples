# T-05 implementation SKILL.md に Mapper IF の置き場所の判断基準を明記する

## 目的
`.claude/skills/implementation/SKILL.md` の「出力ファイルの格納先・命名規則」表の Mapper IF の置き場所「`common/` または同パッケージ」を、判断基準（単一ジョブ専用は同パッケージ、複数ジョブで共有するものは `common/`）が分かる書き方に変える（Issue #64）。

## 入力
- `.claude/skills/implementation/SKILL.md`（「出力ファイルの格納先・命名規則」の表の `| Mapper IF / XML |` の行）
- `docs/architecture.md` §2.1（`common/` は「複数ジョブで共有するエンティティ・Mapper」）

## 成果物
- `.claude/skills/implementation/SKILL.md`（1ファイル。表の1行の書き換え）

## 受け入れ基準
- 判断基準が書かれている：`grep -c '単一ジョブ専用は同パッケージ、複数ジョブで共有するものは .common/.（エンティティも同じ）' .claude/skills/implementation/SKILL.md` が `1`
- 旧い書き方がリポジトリに残っていない：`git grep -l 'または同パッケージ' -- ':!vault/'` の出力が空
- smoke の参照検査が通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`

## 決定済み
- 書き換えるのは表の `| Mapper IF / XML |` の行の2列目の前半だけ。XML の格納先 `src/main/resources/mapper/{Xxx}Mapper.xml` は変えない
- 書き換え後の行は、次の行をそのまま（`common/` と XML のパスはバッククォートで囲む）にする：

| Mapper IF / XML | 単一ジョブ専用は同パッケージ、複数ジョブで共有するものは `common/`（エンティティも同じ） / `src/main/resources/mapper/{Xxx}Mapper.xml` |

- 表の他の行・見出し・本文は変えない。表の列数（2列）を変えない
- `docs/architecture.md` §2.1 のツリーのコメント（`common/` は「複数ジョブで共有するエンティティ・Mapper」）は既にこの基準と合うので変えない（ゴールの範囲は SKILL.md の明記）
- 旧い書き方の残りの確認から `vault/` を除くのは、計画票・タスク票がこの旧い文言を説明として含むため
- このタスクはコード（batch-sample の移動）に依存しない。T-01〜T-04 と並行してよい

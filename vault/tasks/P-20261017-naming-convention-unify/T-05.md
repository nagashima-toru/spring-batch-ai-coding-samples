# T-05 NotifyCandidateProcessor を NotifyCandidateItemProcessor に改名する（コード・テスト）

## 目的
T-04 で改訂した設計書どおりに、`job_announcement_notify` の Processor クラスとその単体テストを §11 の `{Xxx}ItemProcessor` に合う名前に改名する。

## 入力
- `docs/projects/announcement-notification/detail-design/ANNOUNCE-001.md`（T-04 で改訂済み）
- `batch-sample/src/main/java/com/example/batch/sample/job_announcement_notify/NotifyCandidateProcessor.java`
- `batch-sample/src/main/java/com/example/batch/sample/job_announcement_notify/AnnouncementNotifyJobConfig.java`
- `batch-sample/src/test/java/com/example/batch/sample/job_announcement_notify/NotifyCandidateProcessorTest.java`

## 成果物
- 主な成果物：`batch-sample/src/main/java/com/example/batch/sample/job_announcement_notify/NotifyCandidateItemProcessor.java`（クラスの改名）
- 付随して変えるファイル：
  - `batch-sample/src/main/java/com/example/batch/sample/job_announcement_notify/NotifyCandidateProcessor.java`（削除。改名元）
  - `batch-sample/src/main/java/com/example/batch/sample/job_announcement_notify/AnnouncementNotifyJobConfig.java`（型の参照）
  - `batch-sample/src/test/java/com/example/batch/sample/job_announcement_notify/NotifyCandidateItemProcessorTest.java`（テストの改名先）
  - `batch-sample/src/test/java/com/example/batch/sample/job_announcement_notify/NotifyCandidateProcessorTest.java`（削除。改名元）

- 旧クラス名がリポジトリに残っていない（`git grep -n NotifyCandidateProcessor -- . ':!vault'` の出力が空）

- ジョブ名・Step 名・Reader の名前に触れていない（`git diff --merge-base work/p-20261017-naming-convention-unify -- batch-sample/src/main/java/com/example/batch/sample/job_announcement_notify/AnnouncementNotifyJobConfig.java | grep -c -e 'Builder(' -e 'setName'` の出力が `0`）

## 決定済み
- 改名は `git mv` で行う（main と test の2ファイル）。クラス宣言・コンストラクタ名・`AnnouncementNotifyJobConfig.java` の型（引数の型・Bean メソッドの戻り値の型・`new`）・テストのクラス名と `new` の型を新しい名前にする
- `AnnouncementNotifyJobConfig.java` の Bean メソッド名 `notifyCandidateProcessor` と Step 定義の引数名 `notifyCandidateProcessor` は変えない（Bean 名の規約への適合は Issue #60 の範囲外）。Reader の Bean 名・`setName("notifyTargetReader")`・`StepBuilder`/`JobBuilder` の名前は Spring Batch のメタデータに残るため変えない
- Javadoc の本文、テストのフィールド名 `processor`・テストメソッド名・テストの中身は変えない
- 結合テスト（`AnnouncementNotifyJobIT.java`）はこのクラス名を参照していないので変えない。`-DskipITs` のため結合テストはこのタスクの基準では実行しない
- ビルドには JDK 25 が要る。オーケストレーターが apt の `openjdk-25-jdk-headless` を入れ、`~/.mavenrc` で `JAVA_HOME=/usr/lib/jvm/java-25-openjdk-amd64` を設定済み（main の状態でこのビルドが成功することを確認済み）。環境に JDK 25 が無く `release version 25 not supported` で失敗する時は、受け入れ基準を読み替えず `blocked` にして question に書く
- Flyway のマイグレーションファイルは変えない

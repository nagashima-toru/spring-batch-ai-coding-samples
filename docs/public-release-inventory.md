# 公開前の棚卸し結果

リポジトリを public にした時に誰でも見られる情報（作業ツリー・git 履歴・リモートのブランチと PR の ref）から、シークレット・個人情報・内部情報を洗い出した結果。実在の機微な情報（シークレット・キー・トークン、実在の AWS アカウント ID・ARN、内部ホスト名・社内 URL、顧客名・社外秘の案件情報）は、作業ツリー・履歴のどちらにも見つからなかった。

## 対象と方法

- 公開対象：`git ls-files` に出る全ファイルと、`git log --all` に出る全コミット（内容・メッセージ・作成者）。全203コミット
- 除外：`target/` などのビルド生成物は `.gitignore` 対象で git に入らないため、公開対象ではなく調べていない
- 走査前の取得：`git fetch origin` でリモートのブランチを、`git fetch origin '+refs/pull/*/head:refs/remotes/origin/pr/*'` で PR の ref（36件）を取得した（ローカルの ref を足すだけで非破壊）。外部ツール（gitleaks など）は使わず、`git grep` と `git log -G` と履歴 diff の文字列検索で調べた
- 観点と結果
  - シークレットの形（AWS アクセスキー・秘密鍵・GitHub トークン・Slack トークン）：作業ツリー（`git grep`）も履歴（`git log --all -G`）も該当なし
  - パスワード・トークン風の代入：履歴の追加・削除行を `password`・`secret`・`token`・`api_key` で検索。下表の固定値・ダミー値のみ
  - AWS アカウント ID・ARN：12桁の数字と `arn:aws` を検索。出るのは例示値 `123456789012` のみ（`docs/aws-setup.md` とその旧版）
  - 内部ホスト名・社内 URL・IP アドレス：URL のホスト部と IPv4 形式を検索。出るのは `localhost`・Maven/Spring/GitHub/AWS 等の公開サイト・`example.com`・バージョン番号（`4.10.4.1` など IP に見えるもの）のみ。社内のものは無い
  - メールアドレス：作業ツリーと履歴の内容に出るのは `example.com` のテスト用データと、`git@github.com`（SSH の URL 形式）のみ。`example.com` は RFC 2606 の予約ドメインでテスト用のため対象外とした。個人のメールアドレスはコミットの作成者情報にだけある（下の履歴の表）
  - 案件名・顧客名など社外秘になりうる語：`docs/projects/` を含め、サンプルの業務名（顧客・拠点・ユーザーのテスト用データ）のみで、実在の顧客名・案件名は見当たらない

## 作業ツリーの結果

| 種別 | 場所 | 判断 | 対応 |
|---|---|---|---|
| AWS アカウント ID・ARN | docs/aws-setup.md | アカウント ID `123456789012` と ARN は AWS 公式ドキュメントの例示値（ダミー値）。OIDC の信頼ポリシーの `sub` にリポジトリ名が入るのは公開情報で問題なし | 対応なし |
| 固定パスワード | docker/compose.yaml | `batch_admin` はローカル用 PostgreSQL の固定値で、コメントで「ローカル専用。本番は Secrets Manager から注入」と明示済み | 対応なし |
| 固定パスワード | batch-sample/src/main/resources/application-local.yml | `batch_admin` はローカル専用のコミット済み固定値で、コメントで明示済み（本番系は環境変数注入） | 対応なし |
| ダミーのトークン | batch-sample/src/main/resources/application.yml | `SAMPLE05_API_TOKEN` の既定値 `local-dummy-token` はローカル・テスト用のダミー値（環境変数で上書きする形）。実在のトークンではない | 対応なし |

## 人への報告事項

履歴を書き換えない前提で公開すると、次が誰でも見られるようになる。どれを行うかはここでは決めない。

- 作成者のメールアドレス：所有者の53コミットに個人のメールアドレスが入っている
  - 取りうる対応：今後のコミットに GitHub の noreply アドレスを使う（`git config user.email` の変更と、GitHub の Settings で「メールアドレスを非公開にする」を有効にする）。過去分は履歴の書き換えが要るが、PR の ref が残るため完全には消せない
- Claude-Session の URL：37コミットのメッセージに残っている
  - 取りうる対応：そのまま公開する。今後のコミットで付けない設定にする
- PR の ref：36件。GitHub 側で消せず、マージ前のコミットも参照できる
  - 取りうる対応：そのまま公開する。どうしても消したい場合は GitHub サポートへの依頼になる
- 残存ブランチ：`ccr-841df633-5hhfa9`・`ccr-9e7b5503-1u3jk6`・`work/p-20261011-harness-rules` の3本
  - 取りうる対応：不要なら公開前に人が削除する。残す場合は中身を確認済み（機微な情報なし）
- 履歴の書き換え自体は、機微な情報が見つからなかったため行わない前提とした
